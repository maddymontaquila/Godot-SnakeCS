# GodotCon Aspire slides

Reveal.js redesign of the GodotCon talk.

## Run

```powershell
cd .\slides
npm install
npm run start
```

Open the local URL shown by Vite.

## Speaker notes

Press `S` while presenting to open the Reveal.js speaker view.

## PDF export

Run the deck, then open:

```text
http://127.0.0.1:5173/?print-pdf
```

Use the browser print dialog to save as PDF.
